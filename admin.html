Import IEC candidate export

Upload only a file you are authorised to use from the IEC. This version accepts CSV. The importer hashes ID numbers and does not retain raw ID numbers.

Required CSV columns (case-insensitive): ID Number, Names, Surname, Municipality, Ward. Optional: Candidate Status. If the official export uses different headings, map them to these headings in a controlled copy. Keep the original export secure and delete temporary copies when no longer needed.
